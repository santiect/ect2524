				\texttt{.csv}, planilha\dots) com código Python;
			\item montar os parâmetros do modelo \textbf{por programa},
				não copiando número a número;
			\item rodar \textbf{um laço} sobre várias instâncias e
				coletar resultados numa tabela;
		\end{itemize}
		\item A formulação e o modelo vamos construir \textbf{ao vivo},
			em Python, durante a aula;
		\item Estes slides trazem só a \textbf{descrição do problema} e a
			\textbf{colinha de comandos} do \texttt{amplpy}.
	\end{itemize}
\end{frame}

\begin{frame}
	\frametitle{Otimização como componente de software}
	\begin{itemize}
		\item A troca de dados em experimentos é apenas um dos usos;
		\item Chamar o solver a partir de uma linguagem de \textbf{propósito
			geral} permite que a otimização seja \textbf{parte de um
			software};
		\item O modelo pode ser \textbf{embarcado} em:
		\begin{itemize}
			\item um \textbf{app} ou site onde o usuário final entra com
				os dados e recebe a solução;
			\item um \textbf{sistema de apoio à decisão} de uma empresa
				(roteirização, escalas, estoque\dots) que roda sozinho;
			\item um \textbf{pipeline} que lê banco de dados / API,
				otimiza e grava o resultado de volta;
		\end{itemize}
		\item O solver deixa de ser uma ferramenta que \emph{nós}
			operamos e passa a ser um \textbf{componente} que entrega
			decisão para \textbf{outras pessoas}.
	\end{itemize}
\end{frame}

\section{O Problema de Transbordo}
%------------------------------------------------------------

\begin{frame}
	\frametitle{O contexto}
	\begin{itemize}
		\item Uma empresa do ramo de \textbf{bebidas} precisa organizar a
			distribuição para o feriado de \textbf{carnaval};
		\item A rede tem \textbf{três camadas}:
		\begin{itemize}
			\item \textbf{fábricas} produzem o produto;
			\item \textbf{centros de distribuição} recebem das fábricas e
				repassam;
			\item \textbf{clientes} têm uma demanda a ser atendida;
		\end{itemize}
		\item O produto só chega ao cliente \textbf{passando por um
			centro} -- daí o nome \emph{transbordo} (troca de veículo /
			ponto intermediário).
	\end{itemize}
\end{frame}

\begin{frame}
	\frametitle{Custos envolvidos}
	\begin{itemize}
		\item \textbf{Transporte} (custo variável, por unidade):
		\begin{itemize}
			\item $c_{ij}$: produzir na fábrica $i$ e levar ao centro $j$;
			\item $t_{jk}$: armazenar no centro $j$ e entregar ao cliente $k$;
		\end{itemize}
		\item \textbf{Custo fixo} (pago uma vez, só se a instalação for usada):
		\begin{itemize}
			\item $f_i$: abrir/operar a fábrica $i$;
			\item $h_j$: abrir/operar o centro $j$;
		\end{itemize}
		\item \textbf{Capacidade} (limite de quanto passa pela instalação):
		\begin{itemize}
			\item $g_i$: capacidade da fábrica $i$;
			\item $q_j$: capacidade do centro $j$;
		\end{itemize}
		\item \textbf{Demanda}: $d_k$ unidades exigidas pelo cliente $k$.
	\end{itemize}
\end{frame}

\begin{frame}
	\frametitle{O que precisamos decidir}
	\begin{itemize}
		\item Quais \textbf{fábricas} abrir e quais \textbf{centros} abrir;
		\item Quanto produto enviar em \textbf{cada trecho}
			fábrica~$\rightarrow$~centro e centro~$\rightarrow$~cliente;
		\item Regras que a solução tem que respeitar:
		\begin{itemize}
			\item nenhuma instalação passa mais do que sua capacidade;
			\item a demanda de cada cliente é atendida \textbf{exatamente};
			\item \textbf{conservação de fluxo} no centro: tudo que entra
				sai (o centro não acumula estoque);
			\item só há fluxo saindo de uma instalação se ela estiver
				\textbf{aberta}.
		\end{itemize}
		\item \textbf{Objetivo}: minimizar o custo total (fixos + variáveis).
	\end{itemize}
\end{frame}

\section{O arquivo de dados}

\begin{frame}[fragile]
	\frametitle{Formato do \texttt{transbordo.txt}}
	\begin{lstlisting}
2 3 3
80 90 40
120 100
300 250
70 90 66
60 80 100
10 8 20
20 6 11
7 5 10
5 4 3
10 8 6
	\end{lstlisting}
	\begin{itemize}
		\item linha 1: \texttt{m n p} -- nº de fábricas, centros, clientes;
		\item linha 2: demandas $d_k$ ($p$ valores);
		\item linhas 3--4: $g_i$ e $f_i$ das fábricas ($m$ valores cada);
		\item linhas 5--6: $q_j$ e $h_j$ dos centros ($n$ valores cada);
		\item próximas $m$ linhas: matriz $c_{ij}$ ($n$ colunas);
		\item próximas $n$ linhas: matriz $t_{jk}$ ($p$ colunas).
	\end{itemize}
\end{frame}

\section{amplpy: passo a passo}
%------------------------------------------------------------

\begin{frame}[fragile]
	\frametitle{Preparar o ambiente}
	\begin{itemize}
		\item \texttt{amplpy} = ponte Python $\leftrightarrow$ AMPL; o
			módulo \texttt{highs} traz o solver HiGHS;
		\item licença acadêmica gratuita em \url{https://ampl.com}.
	\end{itemize}
	\begin{lstlisting}[language=Python,basicstyle=\ttfamily\small]
pip install amplpy

python -m amplpy.modules install highs
python -m amplpy.modules activate <sua-licenca-uuid>
	\end{lstlisting}
\end{frame}

\begin{frame}[fragile]
	\frametitle{Passo 1 -- importar e instanciar}
	\begin{itemize}
		\item Todo o trabalho passa por um objeto \texttt{AMPL}.
	\end{itemize}
	\begin{lstlisting}[language=Python,basicstyle=\ttfamily\small]
from amplpy import AMPL

ampl = AMPL()
	\end{lstlisting}
\end{frame}

\begin{frame}[fragile]
	\frametitle{Passo 2 -- carregar o modelo}
	\begin{itemize}
		\item Duas formas: escrever o modelo \textbf{inline} ou ler de um
			arquivo \texttt{.mod}.
	\end{itemize}
	\begin{lstlisting}[language=Python,basicstyle=\ttfamily\small]
# opcao 1: inline
ampl.eval(r"""
    param n > 0;
    var x{1..n} >= 0;
    minimize custo: ...;
""")

# opcao 2: de um arquivo
ampl.read("modelo.mod")
	\end{lstlisting}
\end{frame}

\begin{frame}[fragile]
	\frametitle{Passo 3 -- passar um escalar}
	\begin{itemize}
		\item A chave entre colchetes é o nome do \texttt{param} no modelo.
	\end{itemize}
	\begin{lstlisting}[language=Python,basicstyle=\ttfamily\small]
ampl.param["n"] = dados["n"]
	\end{lstlisting}
\end{frame}

\begin{frame}[fragile]
	\frametitle{Passo 4 -- passar um vetor}
	\begin{itemize}
		\item Um vetor vira um \texttt{dict} \{índice: valor\};
		\item no AMPL os índices começam em \textbf{1}.
	\end{itemize}
	\begin{lstlisting}[language=Python,basicstyle=\ttfamily\small]
# dados["c"] == [10, 8, 20]
ampl.param["c"] = {j + 1: dados["c"][j]
                   for j in range(dados["n"])}
	\end{lstlisting}
\end{frame}

\begin{frame}[fragile]
	\frametitle{Passo 5 -- passar uma matriz}
	\begin{itemize}
		\item Uma matriz vira um \texttt{dict} \{(i, j): valor\}.
	\end{itemize}
	\begin{lstlisting}[language=Python,basicstyle=\ttfamily\small]
# dados["d"][i][j]
ampl.param["d"] = {(i + 1, j + 1): dados["d"][i][j]
                   for i in range(dados["m"])
                   for j in range(dados["n"])}
	\end{lstlisting}
\end{frame}

\begin{frame}[fragile]
	\frametitle{Passo 6 -- escolher e configurar o solver}
	\begin{itemize}
		\item \texttt{timelim}: tempo limite em segundos.
	\end{itemize}
	\begin{lstlisting}[language=Python,basicstyle=\ttfamily\small]
ampl.set_option("solver", "highs")
ampl.set_option("highs_options", "timelim=60 outlev=1")
	\end{lstlisting}
\end{frame}

\begin{frame}[fragile]
	\frametitle{Passo 7 -- resolver (e cronometrar)}
	\begin{lstlisting}[language=Python,basicstyle=\ttfamily\small]
import time

t0 = time.perf_counter()
ampl.solve()
tempo = time.perf_counter() - t0
	\end{lstlisting}
\end{frame}

\begin{frame}[fragile]
	\frametitle{Passo 8 -- ler o status}
	\begin{lstlisting}[language=Python,basicstyle=\ttfamily\small]
ampl.solve_result   # 'solved', 'limit', 'infeasible', ...
	\end{lstlisting}
\end{frame}

\begin{frame}[fragile]
	\frametitle{Passo 9 -- objetivo, limitante inferior e gap}
	\begin{itemize}
		\item \texttt{bestbound} e \texttt{relmipgap}: só após resolver
			um modelo \textbf{inteiro}.
	\end{itemize}
	\begin{lstlisting}[language=Python,basicstyle=\ttfamily\small]
custo = ampl.get_objective("custo").value()
lb    = ampl.get_value("custo.bestbound")
gap   = ampl.get_value("custo.relmipgap")
	\end{lstlisting}
\end{frame}

\begin{frame}[fragile]
	\frametitle{Passo 10 -- valores das variáveis}
	\begin{itemize}
		\item Variável binária: considerar aberta quando o valor $> 0{,}5$.
	\end{itemize}
	\begin{lstlisting}[language=Python,basicstyle=\ttfamily\small]
y = ampl.get_variable("y").get_values().to_list()
x = ampl.get_variable("x").get_values().to_pandas()
	\end{lstlisting}
\end{frame}

\begin{frame}[fragile]
	\frametitle{Juntando tudo: laço sobre as instâncias}
	\begin{lstlisting}[language=Python,basicstyle=\ttfamily\tiny]
import time, pandas as pd

arquivos = ["inst1.txt", "inst2.txt", "inst3.txt"]
linhas = []
for arq in arquivos:
    dados = ler_dados(arq)
    ampl = AMPL()                     # modelo NOVO a cada instancia:
    ampl.read("modelo.mod")           # evita erro de parametro "ja definido"
    ampl.param["m"] = dados["m"]
    # ... injetar os demais parametros ...
    ampl.set_option("solver", "highs")
    ampl.set_option("highs_options", "timelim=60")
    t0 = time.perf_counter()
    ampl.solve()
    linhas.append({
        "instancia": arq,
        "objetivo": ampl.get_objective("custo").value(),
        "lb": ampl.get_value("custo.bestbound"),
        "gap": ampl.get_value("custo.relmipgap"),
        "tempo": time.perf_counter() - t0,
        "status": ampl.solve_result})

tabela = pd.DataFrame(linhas)         # uma linha por instancia
print(tabela)
	\end{lstlisting}
\end{frame}

\section{Roteiro do exemplo}
%------------------------------------------------------------

\begin{frame}
	\frametitle{Roteiro do exemplo}
	\begin{enumerate}
		\item Escrever \texttt{ler\_dados(arquivo)}: abre o
			\texttt{transbordo.txt} e devolve um dicionário
			(\texttt{m, n, p, d, g, f, q, h, c, t});
		\item Escrever o \textbf{modelo AMPL} do transbordo (variáveis de
			abertura, variáveis de fluxo, objetivo, restrições);
		\item Escrever o \textbf{script Python}: lê os dados, injeta nos
			parâmetros, resolve;
		\item \textbf{Ler a solução}: quais fábricas e centros abriram,
			quanto passa em cada trecho, custo total, e também
			\texttt{solve\_result}, LB, gap e tempo;
		\item Fechar com o \textbf{laço sobre várias instâncias}
			montando a tabela de resultados.
	\end{enumerate}
\end{frame}
